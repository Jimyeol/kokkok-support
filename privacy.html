1. 처리하는 정보

구독콕콕은 사용자가 앱 안에서 직접 입력한 정보를 기기 안에 저장합니다. 저장될 수 있는 정보는 다음과 같습니다.

  • 구독 서비스명, 카테고리, 아이콘 설정
  • 요금, 통화, 결제 주기, 첫 결제일, 해지 예정일
  • 결제 수단 메모, 알림 설정일, 사용자가 입력한 메모
  • 화면 모드, 환율 설정 같은 앱 설정값

사용자가 구독 아이콘으로 사진을 선택하면 앱은 선택한 사진을 앱 전용 저장 공간에 복사합니다. 앨범의 원본 사진은 앱이 삭제하지 않습니다.

2. 예상 계산 안내

앱이 보여주는 금액, 결제일, D-day, 통계는 사용자가 입력한 값을 바탕으로 계산한 예상 정보입니다. 구독콕콕은 실제 결제 성공 여부를 확인하지 않으며, 외부 구독 서비스를 자동으로 해지하거나 변경하지 않습니다.

3. 외부 전송

구독콕콕은 사용자가 입력한 구독명, 금액, 결제일, 결제 수단, 메모, 사진을 앱 서버로 전송하지 않습니다.

달러 환율 자동 갱신을 켠 경우 앱은 Frankfurter v1 공개 환율 API에 USD/KRW 환율 요청을 보냅니다. 이 요청에는 사용자가 입력한 구독 정보나 금액이 포함되지 않습니다. Frankfurter는 공개 API가 개인 데이터, IP 주소, 요청 URL을 수집하거나 기록하지 않는다고 설명합니다.

Frankfurter는 중앙은행과 공식 기관의 공개 기준환율을 모아 제공하며, v1 최신 환율은 최신 영업일 기준으로 일별 갱신됩니다. ECB 통계는 출처를 표기하고 통계를 수정하지 않는 조건에서 상업적·비상업적 재사용이 허용됩니다. 구독콕콕은 환율 값을 사용자가 입력한 달러 금액의 원화 예상액을 계산하는 데만 사용합니다.

환율 출처: Frankfurter v1 API, Frankfurter License & Terms, ECB statistics reuse policy. Source: Frankfurter and ECB statistics.

4. 권한 사용

  • 알림: 사용자가 설정한 결제 예정일 전에 로컬 알림을 보내기 위해 사용합니다.
  • 사진 보관함: 사용자가 구독 아이콘으로 쓸 사진을 선택할 때만 사용합니다.
  • 인터넷: 달러 환율 자동 갱신을 위해 사용합니다.
  • 부팅 완료 수신(Android): 기기 재시작 후 예약된 로컬 알림을 유지하기 위해 사용합니다.

5. 보관 및 삭제

구독 정보와 설정은 사용자의 기기 안에 저장됩니다. 사용자는 앱 안에서 개별 구독을 삭제하거나 설정에서 모든 구독 데이터를 지울 수 있습니다.

앱에서 모든 구독 데이터를 지우면 앱이 저장한 구독 정보와 앱 전용 저장 공간에 복사한 아이콘 파일도 함께 삭제됩니다. 앨범에 있던 원본 사진은 삭제되지 않습니다.

앱을 삭제하면 앱 전용 저장 공간의 데이터는 운영체제 정책에 따라 삭제됩니다. 다만 사용자가 iCloud, Google 백업, 기기 백업 또는 복원 기능을 켠 경우, 운영체제 설정에 따라 앱 데이터가 백업되거나 새 기기로 복원될 수 있습니다.

6. 제3자 제공 및 공유

현재 버전은 사용자가 입력한 구독 정보를 제3자에게 제공하거나 공유하지 않습니다. 환율 요청은 구독 정보 없이 환율 조회 목적으로만 사용됩니다.

7. 아동 개인정보

구독콕콕은 아동을 주 대상 사용자로 제공되는 서비스가 아니며, 현재 버전은 회원가입이나 계정 기능을 제공하지 않습니다.

8. 변경
