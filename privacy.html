1. 처리하는 정보

구독콕콕은 사용자가 앱 안에서 직접 입력한 정보를 기기 안에 저장합니다. 저장될 수 있는 정보는 다음과 같습니다.

  • 구독 서비스명, 카테고리, 아이콘 설정
  • 요금, 통화, 결제 주기, 첫 결제일, 해지 예정일
  • 결제 수단 메모, 알림 설정일, 사용자가 입력한 메모
  • 화면 모드, 앱 언어, 지역, 기준 통화, 환율 설정 같은 앱 설정값

사용자가 구독 아이콘으로 사진을 선택하면 앱은 선택한 사진을 앱 전용 저장 공간에 복사합니다. 앨범의 원본 사진은 앱이 삭제하지 않습니다.

카드 결제 알림 감지 (Android, 선택)

Android에서 사용자가 "카드 결제 알림 감지"를 켜고 알림 접근을 허용한 경우, 구독콕콕은 사용자가 직접 고른 카드·은행 앱에서 설정 이후 새로 도착한 알림만 기기 안에서 분석해 가맹점명, 금액, 통화, 알림 수신 시각을 찾고 구독으로 등록할지 확인할 후보를 제안합니다. 이 기능은 기본적으로 꺼져 있으며, 앱을 닫은 상태에서도 동작할 수 있습니다.

  • 선택하지 않은 앱의 알림 내용은 분석하거나 저장하지 않습니다. 문자 메시지함을 읽거나 카드·은행 계정에 로그인하지 않으며, 카드·은행 서버에서 결제 내역을 가져오지 않습니다.
  • 알림 원문과 카드·계좌번호는 저장하지 않습니다. 저장하는 것은 후보 요약(가맹점 또는 제안 서비스명, 금액, 통화, 수신 시각, 알림을 보낸 앱)과 감지 설정(켜기 상태, 선택한 앱, 제안을 끈 가맹점, 중복 방지 정보)뿐입니다.
  • 후보 요약은 앱 전용 저장 공간에 최대 50개까지 보관하며, 30일이 지난 후보는 다음에 감지 화면을 열거나 새 결제를 처리할 때 삭제됩니다. 이 정보는 운영체제 자동 백업과 구독콕콕 백업 파일에 포함되지 않습니다.
  • 알림 원문과 후보 요약은 서버, 외부 AI, 광고·분석 도구로 보내지 않습니다. 구독으로 자동 등록하거나 결제·해지하지 않으며, 사용자가 내용을 확인하고 저장해야 구독으로 등록됩니다.
  • 감지 화면에서 기능을 끄거나 후보를 삭제할 수 있고, Android 설정에서 알림 접근을 해제할 수 있습니다. 기능을 끄면 새 알림을 분석하지 않습니다.

2. 예상 계산 안내

앱이 보여주는 금액, 결제일, D-day, 통계는 사용자가 입력한 값을 바탕으로 계산한 예상 정보입니다. 구독콕콕은 실제 결제 성공 여부를 확인하지 않으며, 외부 구독 서비스를 자동으로 해지하거나 변경하지 않습니다.

3. 외부 전송

구독콕콕은 사용자가 입력한 구독명, 금액, 결제일, 결제 수단, 메모, 사진을 앱 서버로 전송하지 않습니다.

환율 자동 갱신을 켠 경우 앱은 Frankfurter v1 공개 환율 API에 미국 달러(USD) 기준 환율 요청을 보냅니다. 이 요청에는 조회할 통화 코드(KRW, JPY, GBP, AUD, CAD, EUR)만 포함되며, 사용자가 입력한 구독 정보나 금액은 포함되지 않습니다. Frankfurter는 공개 API가 개인 데이터, IP 주소, 요청 URL을 수집하거나 기록하지 않는다고 설명합니다.

Frankfurter는 중앙은행과 공식 기관의 공개 기준환율을 모아 제공하며, v1 최신 환율은 최신 영업일 기준으로 일별 갱신됩니다. ECB 통계는 출처를 표기하고 통계를 수정하지 않는 조건에서 상업적·비상업적 재사용이 허용됩니다. 구독콕콕은 환율 값을 사용자가 입력한 금액을 사용자가 고른 기준 통화로 환산한 예상액을 계산하는 데만 사용합니다.

환율 출처: Frankfurter v1 API, Frankfurter License & Terms, ECB statistics reuse policy. Source: Frankfurter and ECB statistics.

앱 사용 통계와 오류 기록 (Firebase)

앱을 개선하기 위해 Google의 Firebase Analytics와 Firebase Crashlytics를 사용합니다. 전송되는 정보는 다음과 같습니다.

  • 사용 통계(Firebase Analytics): 화면 이동, 구독 추가·수정·삭제, 위젯 추가, 백업 같은 기능 사용 기록과 대표 서비스 종류(예: netflix), 카테고리, 결제 주기, 통화, 등록한 구독 개수 구간, 앱 버전, 기기 종류, OS 버전, 대략적인 국가·지역, 앱 설치 단위의 무작위 식별자
  • 오류 기록(Firebase Crashlytics): 앱이 비정상 종료되거나 오류가 났을 때의 오류 내용, 기기 모델, OS 버전, 앱 버전, 앱 설치 단위의 무작위 식별자

구독 이름, 금액, 결제일, 결제 수단, 메모, 사진은 보내지 않습니다. 광고 ID(Android 광고 ID, iOS IDFA)와 iOS 기기 식별자(IDFV)는 수집하지 않으며, 광고나 맞춤 광고에 사용하지 않습니다. 이 정보는 Google LLC가 Firebase 서비스 제공을 위해 처리하며, 국외(미국 등)의 Google 서버에 저장될 수 있습니다. Firebase의 기본 보관 기간(사용 통계 최대 14개월, 오류 기록 90일)이 지나면 삭제됩니다. 디버그(개발) 빌드에서는 수집하지 않습니다.

서비스 목록 갱신과 요금 변경 알림 (Firebase)

서비스 요금이 바뀌었을 때 앱 업데이트 없이 반영하기 위해 Google의 Firebase Remote Config로 서비스 목록·요금 정보를 받아옵니다. 이 요청에는 구독 정보나 금액이 포함되지 않습니다. 받아온 요금은 기기 안에서 사용자의 구독과 비교하며, 사용자가 금액을 직접 고치지 않은 구독은 다음 결제일부터 새 요금으로 계산합니다(이전 결제는 예전 요금 그대로).

요금 변경 푸시 알림을 위해 Firebase Cloud Messaging을 사용합니다. 이를 위해 앱 설치 단위의 푸시 토큰이 발급되고, 사용자가 등록한 서비스의 요금 알림 주제(예: price_netflix_kr)를 구독합니다. 구독 이름·금액·결제일 같은 입력 정보는 보내지 않습니다. 푸시 토큰은 Google LLC가 알림 전송을 위해 처리하며, 기기 설정에서 알림을 끄면 알림을 받지 않습니다.

서비스 로고

구독 목록에 서비스의 실제 로고를 보여주기 위해, 로고가 처음 보일 때 Google 파비콘 서비스 또는 해당 서비스의 웹사이트에 서비스 주소(예: netflix.com)로 아이콘을 요청하고, 받은 로고를 기기의 캐시 폴더에 저장합니다. 이 요청에는 구독 금액이나 메모 같은 사용자 입력 정보가 포함되지 않습니다.

백업 파일

설정의 "백업 파일 내보내기"는 구독 정보, 설정, 앱에 복사한 아이콘 사진을 담은 파일을 기기에서 만들고, 사용자가 고른 곳(메신저, 클라우드 드라이브, 파일 앱 등)으로 보냅니다. 이 파일은 구독콕콕 운영자에게 전송되지 않으며, 저장한 곳의 정책에 따라 보관됩니다. 백업 파일에는 구독 이름, 금액, 메모가 그대로 들어 있으니 본인만 접근할 수 있는 곳에 보관해 주세요.

4. 권한 사용

  • 알림: 사용자가 설정한 결제 예정일 전에 로컬 알림을 보내기 위해 사용합니다.
  • 사진 보관함: 사용자가 구독 아이콘으로 쓸 사진을 선택할 때만 사용합니다.
  • 인터넷: 환율 자동 갱신, 서비스 목록·요금 갱신, 서비스 로고 불러오기, 요금 변경 알림 수신, 사용 통계·오류 기록 전송을 위해 사용합니다.
  • 부팅 완료 수신(Android): 기기 재시작 후 예약된 로컬 알림을 유지하기 위해 사용합니다.
  • 알림 접근(Android, 선택): 카드 결제 알림 감지를 켜고 동의한 경우에만, 선택한 카드·은행 앱의 결제 알림에서 구독 후보를 찾기 위해 사용합니다.

5. 보관 및 삭제

구독 정보와 설정은 사용자의 기기 안에 저장됩니다. 사용자는 앱 안에서 개별 구독을 삭제하거나 설정에서 모든 구독 데이터를 지울 수 있습니다.

앱에서 모든 구독 데이터를 지우면 앱이 저장한 구독 정보와 앱 전용 저장 공간에 복사한 아이콘 파일도 함께 삭제됩니다. 앨범에 있던 원본 사진은 삭제되지 않습니다.

앱을 삭제하면 앱 전용 저장 공간의 데이터는 운영체제 정책에 따라 삭제됩니다. 다만 사용자가 iCloud, Google 백업, 기기 백업 또는 복원 기능을 켠 경우, 운영체제 설정에 따라 앱 데이터가 백업되거나 새 기기로 복원될 수 있습니다.

홈 화면·잠금 화면 위젯을 표시하기 위해 다가오는 결제 정보(서비스 이름, 금액, 결제일, 아이콘)를 기기 안의 위젯 공유 저장 공간에 저장합니다. 이 정보는 기기 밖으로 전송되지 않습니다.

6. 제3자 제공 및 처리 위탁

사용자가 입력한 구독 정보는 제3자에게 제공하거나 공유하지 않습니다. 앱 사용 통계·오류 기록, 서비스 목록 갱신, 요금 변경 푸시 알림은 Google LLC(Firebase)에 처리를 맡깁니다. 환율 요청은 구독 정보 없이 환율 조회 목적으로만 사용됩니다.

7. 아동 개인정보

구독콕콕은 아동을 주 대상 사용자로 제공되는 서비스가 아니며, 현재 버전은 회원가입이나 계정 기능을 제공하지 않습니다.
