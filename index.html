앱이 하는 일

구독 이름, 요금, 결제 주기, 결제일, 알림일, 메모를 사용자가 직접 등록하면 앱 안에서 다음 결제일과 월 기준 지출을 계산합니다.

알아둘 점

구독콕콕의 금액과 결제일은 사용자가 입력한 값을 바탕으로 한 예상 정보입니다. 실제 결제 성공 여부를 확인하거나 구독 서비스 해지를 대신 처리하지 않습니다.

데이터 보관

구독 정보는 기기 안에 저장됩니다. 앱 설정의 전체 삭제나 앱 삭제로 앱 데이터가 삭제되며, 운영체제 백업과 복원 설정에 따라 기기 데이터가 백업될 수 있습니다.

구독을 해지해 주나요?

아니요. 앱은 해지 예정일을 기록하고 이후 계산에서 제외할 수 있지만, 각 서비스의 실제 구독 해지는 사용자가 해당 서비스에서 직접 해야 합니다.

실제 결제 내역을 읽나요?

아니요. 카드, 은행, 이메일, 문자, 앱스토어 결제 내역을 자동으로 읽지 않습니다. 사용자가 입력한 내용을 기준으로 계산합니다.

사진 아이콘은 어떻게 되나요?

앨범에서 선택한 사진은 앱 전용 저장 공간에 복사됩니다. 앱에서 데이터를 지우면 앱이 복사한 아이콘 파일은 삭제되지만, 앨범의 원본 사진은 삭제되지 않습니다.

환율 출처

달러 구독료의 원화 환산은 Frankfurter v1 공개 API의 최신 영업일 USD/KRW 환율을 사용합니다. Frankfurter는 중앙은행과 공식 기관의 공개 기준환율을 모아 제공하며, v1 최신 환율은 영업일 기준 일별 갱신됩니다.

ECB 통계는 출처를 표기하고 통계를 수정하지 않는 조건에서 상업적·비상업적 재사용이 허용됩니다. 구독콕콕의 환율 환산은 사용자가 입력한 금액을 이해하기 위한 참고용 예상 계산입니다.
